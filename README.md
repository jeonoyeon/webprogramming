# 나의 웹 연습장

웹프로그래밍 수업에서 배운 내용으로 만든 실습 사이트입니다. 홈, 내 정보, 방명록 세 페이지를 메뉴로 연결하였습니다!

## 페이지

| 페이지 | 파일 | 설명 |
|---|---|---|
| 홈 | `index.html` | 인사말과 수업에서 했던 내용 소개 입니다. |
| 내 정보 | `about.html` | 이메일과 나의 정보들이 적혀있습니다. |
| 방명록 | `guestbook.html` | 이 페이지는 이름과 메시지를 입력하고 목록에 표시 해둔 페이지 입니다. |

## 기능

- 홈에서 인사말 바꾸기와 다크 모드를 사용할 수 있습니다.
- 방명록에서 이름이나 메시지를 비우면 안내 문구가 나옵니다.
- 글을 작성하면 방명록 목록 맨 위에 추가됩니다.
- 방명록 내용은 현재 화면에서만 유지가 되고 새로고침하면 사라집니다.

## 사용한 내용

- `header`, `nav`, `main`, `footer`를 사용해 페이지 구조를 만들었습니다.
- CSS 파일을 따로 만들고 작은 화면에서도 볼 수 있게 크기를 조절하였습니다.
- JavaScript의 클릭 이벤트와 폼 제출 이벤트를 사용하였습니다.
- 입력한 내용을 `textContent`로 목록에 추가하였습니다.
